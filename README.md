## 📦 Instalasi & Menjalankan Lokal

```bash
# Clone repository
git clone https://github.com/rztechdev/rz-about.git

# Masuk ke direktori
cd rz-about

# Install PHP dependencies
composer install

# Install JS dependencies
npm install

# Setup environment
cp .env.example .env
php artisan key:generate

# Build frontend assets
npm run build
# Atau untuk mode dev
npm run dev

# Jalankan server
php artisan serve
```
